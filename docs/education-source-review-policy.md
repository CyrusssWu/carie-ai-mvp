# Education Source Review Policy

## 状态含义

- **verified / 已核对官方来源（摘要）**：记录的特定字段已与指定官方页面对照，具备明确学年、已读来源、实际核对日期及复核期限。不是完整招生章程、官方翻译或录取承诺。
- **needs_review / 资料待核实**：字段缺失、来源不可读、学年不符、时间元数据无效、复核记录来自未来日期，或仅有未核对生成内容。缺失要求显示“尚未核實，請參閱官方網站。”
- **outdated / 请查看最新官方要求**：到达课程所属入学年 9 月 1 日（保守的历史资料边界）、超过 reviewBy，或编辑明确撤销当前性。历史摘要仍可阅读，但不会被展示成最新入学要求。

运行时以香港日历日期（UTC+8）比较，不把香港当天凌晨误判为尚未核对。打开页面、重新取得焦点和每分钟会更新课程卡状态；详情展开后也重新检查并每分钟刷新。浏览器时间不可靠是本地应用的限制，不能取代人工复核。

## 复核频率和责任

指定一位课程资料维护者及另一位具香港升学经验的人工复核者。普通周期每月查看；任何 reviewBy 最多为核对后 90 天，初始 JS3569 使用 30 天，期限 2026-11-15。正式试点前、每轮招生开放、成绩公布与课程变更时须再次人工核对。不得只修改 lastVerifiedAt/reviewBy 延长有效期。

程序不会后台访问官方站点，也没有爬虫或远程自动更新，因此不会知道上游刚刚改了什么。期限内也可能发生更改，学生始终可查看官方链接，并看到“請以院校及招生機構公布的最新資料為準”。

## 院校或 VTC 更新要求时

1. 打开 `src/data/education/programmes.ts` 找到相同课程和学年。把受影响字段及整条记录先标 needs_review；若周期已结束标 outdated。重新部署后停止显示旧的 verified 标签。
2. 亲自打开当届官方课程页、一般要求页、申请渠道和特殊条件。核对代码与全名、入学年份、本地／非本地、全日制／兼读制及联招／非联招。不要用缓存搜索摘要替代页面。
3. 更新 `src/data/education/sources.ts` 的精确 URL、accessedAt、applicableYear、accessStatus、verificationNotes。失效链接应由官方索引寻找新入口；找不到就记录失败及替代索引，不编造规则。
4. 在 `programmes.ts` 分别修改三组要求的 text、admissionYear、sourceIds、verificationStatus。任何未确认字段保留 null/needs_review，整条记录不可标 verified。
5. 新招生周期建立新 ID（例如 `…-2028`），保留旧周期用于追溯；在 `pathways.ts` 更新 relatedProgrammeIds 和 programmeCareers，使页面指向已复核的新周期。不能把旧资料改一个年份就当成新资料。
6. 核对完成后才填写 lastVerifiedAt、适当的 reviewBy、verified；留下逐字段核对记录、人工复核者、日期及例外。现有注释说明理大一般要求页未独立注明 2027/28，因其由 2027 课程页直接链接而按该上下文整理；试点前需再向官方确认这一点。
7. 运行内容验证、类型检查、全部单元测试、构建；在浏览器打开对应职业、课程、历史／缺失状态和官方链接。确认其余职业没有错误显示该课程。
8. 发布静态资源后，用硬刷新核对线上版本；本地数据不会自动推送新内容。浏览器长期离线或持有旧部署可能继续显示旧摘要，但旧版本内置的 reviewBy 到期后应转为过期提示。

## 上线前人工必查

| 项目 | 要求 |
| --- | --- |
| 学年与对象 | 每项要求对应明确招生周期及申请类别 |
| 课程身份 | 官方代码、院校、全名、资格、课程是否仍招收 |
| 一般／特定要求 | 相互独立核对；替代资格、作品集、面试、Band A 等不能遗漏成确定性结论 |
| 内容表述 | 摘要忠实，不能把 AI 建议标为官方事实；最低要求不是保证录取 |
| 路径关系 | 学习方向与故事任务合理相关；不等同职业执照、就业保证或自动适配 |
| 链接 | 直接打开；记录失败；不绕过登录、验证码或访问限制 |
| 隐私 | 学业模块可跳过／删除，导出披露完整，导师摘要先选择再确认；反思默认关闭 |
| 浏览器 | 390px、键盘可操作、弹层焦点、刷新、写入失败、无效体验、无自动传送 |

## 本轮证据与缺口（2026-10-16）

9 条登记：教育局索引、教育局本地升学说明、JUPAS 课程入口、e导航、理大 JS3569 2027、理大一般要求成功读取；VTC 主入口读取错误、iPASS 逾时、E-APP 502。失败不表示网站永久失效，也不能报告所有链接均可正常访问。

未将搜索结果中的 VTC 物流／银发服务课程直接录入，因为完整页面与当届招生条件未能核实。没有未审查的 VTC 课程要求可供学生误读。后续优先补物流与社区领域的当届真实课程；先补人工证据，再扩充数据。

## 人工复核记录模板

```text
Programme ID / Source IDs:
官方机构、课程全名及代码:
适用入学学年、申请对象、渠道:
一般要求官方段落及 URL:
课程要求官方段落及 URL:
其他条件、替代资格、冲突或缺失:
职业映射依据（官方事实／编辑解释分别写）:
实际访问结果与日期（香港时间）:
编辑人员 / 独立复核人员:
状态决定与理由:
下次复核日期:
验证、浏览器测试及部署版本:
```

不保存学生个人资料到来源记录、查询 URL 或维护日志。不做录取概率、自动大学排名、资格淘汰或隐藏计分。
